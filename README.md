## 📘 Overview

Welcome to the **Zero to Advance in DSA** 🚀 — a 30-day structured challenge designed for students, developers, and coding enthusiasts to master Data Structures and Algorithms from scratch.

This repository contains:
- 🎯 **60 carefully selected questions** (2 per day)
- 🧠 From basic arrays to complex dynamic programming
- 📚 With clean, optimal Java solutions
- 🎓 Ideal for interview prep & competitive coding

> “Consistency beats intensity.” Let's code every day! 🔥
---
## 🎯 Goals

- Strengthen core DSA concepts.
- Practice real-world interview-level problems.
- Build consistency through daily commitment.
- Prepare for tech interviews with top companies.
